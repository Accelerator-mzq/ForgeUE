**Goal:** 在已归档 `2026-05-02-comfy-agent-cli-adoption`(image-only)基础上,扩展 `ComfyAgentWorker` 接 ComfyUI 本地 mesh capability(image-to-mesh 路径)。复用 image change 已建立的 CLI subprocess + bundle alias + env vars 基础设施;新增 capability dispatch + mesh executor worker path + ADR-007 边界形式化(`per_task_usd > 0`)+ 异常族 wrap。Audio / video 拆 follow-on change(D3)。

**Architecture:** 单 capability 扩展(`provider-routing` 主,`artifact-contract` / `examples-and-acceptance` / `probe-and-validation` 配套);改 `src/framework/providers/workers/comfy_worker.py`(`ComfyAgentWorker.__init__` 加 `model_id` + `_CAPABILITY_BY_MODEL_ID` + 三段表 `_validate_outputs` + 新方法 `generate_mesh`)+ `src/framework/runtime/executors/generate_mesh.py`(加 `_should_use_comfy_worker_path` + `_generate_via_comfy_worker`,沿用现有 `_resolve_source_image` 流程,内部含 retry loop + 异常族 wrap)+ `config/models.yaml` 加 2 entry(`models.comfy/local-mesh` + `aliases.mesh_local`,**不**动 `providers.comfy_api`)+ `framework.run` / `DryRunPass` probe gate list 扩 `comfy/local-mesh` + 新 bundle `examples/comfy_local_smoke_mesh.json`(image-to-mesh DAG)。**NO** `MeshWorker` ABC 改动 / `MeshCandidate` / `PayloadRef` 字段扩 / `BudgetTracker.is_premium` 新 API。框架侧契约(`HunyuanTokenhubMeshWorker` / `Tripo3DMeshWorker` / `FakeMeshWorker` / `repo.put` / FR-COST 接口)零破坏。

**Tech Stack:** Python 3.12+,标准库 `subprocess` + `shutil` + `pathlib` + `hashlib` + `logging`;无新 Python 依赖。Test runner:`pytest -q`(post-change baseline = 549 + 实测增量 ~25 fence,**不**硬编码)。运行时假设 `D:/AI/ComfyUI/scripts/` + `python -m comfyui_api list / params / run` 可用(由 dry-run probe 强制校验);本机至少 1 个 image-to-mesh manifest(产 `outputs.glb`,可带 auxiliary `outputs.images`)。
