## 3. Add lazy-import fence tests

- [x] 3.1 Create `tests/unit/test_artifact_store_lazy_imports.py` with **four** test functions(F2 codex finding 收紧 + F3 codex finding 加 `__dir__` fence):
  - [x] 3.1.0 **Subprocess helper** — define a `_run_clean_subprocess(script: str)` helper at the top of the test module. The helper MUST: (a) resolve `_REPO_ROOT = Path(__file__).resolve().parents[2]` and `_SRC = _REPO_ROOT / "src"`; (b) build `env = {**os.environ, "PYTHONPATH": str(_SRC) + os.pathsep + os.environ.get("PYTHONPATH", "")}`; (c) call `subprocess.run([sys.executable, "-c", script], env=env, capture_output=True, text=True, check=True, timeout=30)` and return the parsed JSON stdout. Every fence test below **MUST** call this helper, never `subprocess.run` directly. This guarantees subprocess sees working-tree `src/framework/` regardless of pytest main-process `sys.path` mutations, fresh checkout state, or pre-existing pip editable install
  - [x] 3.1.1 `test_import_artifact_store_does_not_pull_repository_or_payload_backends`: subprocess script does (i) `import framework.artifact_store`, (ii) `import framework.artifact_store.hashing`, (iii) **assert `framework.artifact_store.__file__` resolves under the working-tree `src/` path** (defends against accidental match against an old installed package), (iv) print JSON list of `[m for m in sys.modules if m.startswith('framework.artifact_store.')]`. Parent-process assert: list contains only `framework.artifact_store.hashing` (no `repository` / `payload_backends` / `lineage` / `variant_tracker`)
  - [x] 3.1.2 `test_first_access_of_lazy_symbol_loads_submodule_and_caches`: subprocess script (a) imports `framework.artifact_store`, asserts `__file__` under working-tree `src/`, (b) snapshots `sys.modules` keys starting with `framework.artifact_store.`, (c) `getattr(mod, "ArtifactRepository")` once, (d) snapshots again, (e) `getattr(mod, "ArtifactRepository")` a second time, (f) prints JSON `{"before": [...], "after": [...], "identical": (first is second)}`. Parent-process assert: `before` lacks `framework.artifact_store.repository`; `after` contains it; `identical == true`. **Note (S3 codex plan review F1)**: this fence intentionally only asserts `repository in sys.modules` after access, not the **absence** of `lineage` / `payload_backends` / `variant_tracker` —— those WILL also load due to `repository.py:24-29` intra-package imports (cluster materialization), and spec.md Scenario 2 explicitly acknowledges this. The strict per-symbol-isolation contract was relaxed in S3 writeback to match design value (read-only consumer guarantee, codified by Scenario 1) instead of theoretical isolation
  - [x] 3.1.3 **`test_dir_returns_full_public_api_surface_before_any_lazy_access`**(新增,F3 守门): subprocess script (a) `import framework.artifact_store as mod`, asserts `__file__` under working-tree `src/`, (b) prints JSON `{"dir_keys": sorted(dir(mod)), "all": list(mod.__all__)}`. Parent-process assert: every name in `__all__` (9 names: `ArtifactRepository` / `LineageIndex` / `PayloadBackend` / `PayloadBackendRegistry` / `PayloadTooLarge` / `VariantTracker` / `get_backend_registry` / `hash_inputs` / `hash_payload`) **MUST** appear in `dir_keys` even though none have been accessed yet. This守 the "公共 API 表面零变化" promise against future PRs that delete the `__dir__` function
  - [x] 3.1.4 `test_no_callsite_uses_submodule_path`: walk the repo (`pathlib.Path(__file__).resolve().parents[2]`) for all `*.py` files under `src/`, `tests/`, `probes/`, then `re.search` for `from framework\.artifact_store\.(repository|payload_backends|lineage|variant_tracker)` per file; assert zero matches; `framework.artifact_store.hashing` is allowed (whitelist explicit). **Excludes** four explicit paths with reasons embedded in the test as comments: (a) `src/framework/artifact_store/**` itself — intra-package submodule imports (e.g., `repository.py:24-29` importing `lineage` / `payload_backends.base` / `variant_tracker`) are legitimate package-internal structure and not the fence's target; (b) `tests/unit/test_payload_backends.py` — payload_backends sub-package专属测试 consuming `BlobBackend` / `FileBackend` / `InlineBackend` / `file_backend.FILE_MAX_BYTES` which are sub-package internals NOT in `framework/artifact_store/__init__.py::__all__` (this is a legitimate sub-package consumer, not an external-caller fence violation); (c) `openspec/changes/lazy-artifact-store-package-exports/` since example code in design.md quotes the forbidden form; (d) any `*.pyc` / `__pycache__/` paths. The fence target is **out-of-package callers consuming declared `__all__` symbols via the wrong path**, not legitimate sub-package consumers
