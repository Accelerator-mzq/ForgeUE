## Cross-cutting Risks

详见 [design.md ## Risks / Trade-offs](../design.md#risks--trade-offs)。本 plan 强调 implementer 必须警觉的 4 点:

1. **D1 FileMediaSourceFactory API 真实签名风险**:UE 5.x `unreal.FileMediaSourceFactory` 我没在 P4 真机 hands-on 验证;若 `domain_video.py` 实装时发现 API 不同(如需 `unreal.MediaPlayerFactory` 或 `MediaSource` base class),走 round-2 design 修订(沿 a2_mesh round 5 D10 modify 模式)。**STOP** + 回写 design.md D1 + Risks。
2. **D3 Wan 1.3B 模型权重首次拉**:~3GB HuggingFace 拉,网络慢用户体验差。Implementer 在 §11.1 准备步骤显式提示用户预先暖启 ComfyUI,避免 worker_timeout_s=600 在冷启动时耗尽。
3. **D5 `Vedio/` 拼写 IDE 误改风险**:bundle JSON 内 `"Vedio/Wan2.1-..."` 字符串 IDE typo-checker 可能标红。Implementer 在 commit 10 添加 inline 注释 + commit 12-15 docs sync 时反复强调。
4. **D12 + F1 三处 sweep 必须同 commit**:`_is_importable` whitelist + `PermissionPolicy` 字段 + `_OP_ALLOW_ATTR` 映射 三个改动必须在 §8c commit 一起落,否则 `is_op_allowed` 与 `getattr(policy, attr_name)` 矛盾会破坏 video import 默认 allow tier。**STOP** if found split across commits during code review.
